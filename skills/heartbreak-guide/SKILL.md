# 失恋后：按《失恋后自救手册》查了再答

## 第 0 步：先看要不要马上停下

在做任何分析之前，先看用户的话里有没有这几种情况：

- **提到不想活、想伤害自己、「撑不下去了」**：先给 12356（全国心理援助热线）；有具体计划或手边有工具的，说打 120 或去最近的急诊。出处是第 6 节第 2 条。不做劝导式分析，不评价动机，不讲道理。
- **对方正在威胁、跟踪、动手，或者威胁公开私密照片**：先说打 110，再按第 5 节第 3 到 5 条回答。
- **用户不满 18 岁**：补一句 12355（青少年服务台）。
- 其余情况，照下面的步骤走。

## 第 1 步：把正文拿到手

- **本地**：当前目录或上级目录里有 `book/01-头72小时.md`，就直接读 `book/` 下的六个文件。
- **远程**：没有就现取。

```bash
git clone --depth 1 https://github.com/zoey1108/HowToHealHeartbreak.git "${TMPDIR:-/tmp}/hthb"
```

取不到正文就如实告诉用户，不要凭印象复述书的内容。

## 第 2 步：查条目

- 按用户所处的阶段找节：刚分手几天看第 1 节，头两周看第 2 节，几个月看第 3 节，半年以上看第 4 节，钱、合租、纠缠、威胁看第 5 节，觉得不只是难过看第 6 节。阶段只是参考，按用户描述的状态判断。
- 再用关键词在全书搜一遍，别漏了别的节里的相关条目。
- 每条都要读「适用与例外」栏，确认用户的情况没有落在例外里。

## 第 3 步：回答

- 每个建议后面注明出处，写成「（第 2 节第 3 条，证据 B）」。
- 先给动作，再给理由。理由只用条目「说人话」和「收益」栏里已有的内容，不添新数字。
- 证据是 C 级的，要说明「这是通行做法，没有专门的研究」。
- 用户的情况落在「适用与例外」里的，直接按例外那一栏回答。
- **书里没写的，直说书里没写**。可以给常识判断，但要标明那是常识，不是书里的内容。

## 不做的事

- 不教怎么挽回、怎么让对方后悔、怎么试探对方。用户问「怎么复合」，按第 2 节第 5 条回答：复合不是不能谈，但别在半夜、喝了酒、刚吵完的时候谈，头两周先别定。
- 不替用户判断谁对谁错，不评价前任。
- 不做心理诊断，不推荐具体药物。该看医生的，按第 6 节说清楚去挂哪个科。
- 法律问题只给书里的通用口径，个案让用户找律师或报警。
