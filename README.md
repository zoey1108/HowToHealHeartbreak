## 怎么读

- **不用全做**。挑一两条能做的就够了。
- **只看「说人话」那一行就能拿主意**。想核对数字，看「收益」栏和「来源」栏。
- **每条都有「适用与例外」**。失恋这件事个人差异很大，先看这一栏是不是在说你。
- **[在线检索页](https://zoey1108.github.io/HowToHealHeartbreak/)**：可以按阶段、口径、证据等级筛选。要离线用，下载下面的单文件版。

每条建议长这样：

```markdown
### 3. 别反复去看前任的朋友圈和主页，控制不住就先屏蔽
- 成本：不花钱。前几天要忍住点开的冲动，这是最难的部分。
- 说人话：常去看前任主页的人，更难过、更想念，个人成长也更少。删不删好友，研究里有好有坏，关键是别总去看。
- 收益：一项 464 人的问卷研究……只记录、不分组，分不清因果。
- 证据等级：B
- 来源：Marshall TC (2012) … https://doi.org/10.1089/cyber.2012.0125
- 适用与例外：研究用的是 Facebook。换成微信、小红书、抖音，方向大概一样，但没有直接数据。
```

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 法条或官方文件原文；或者荟萃分析、大型队列、随机试验，能给出具体数字 |
| B | 有研究支持，但样本小、只有一项研究，或者说不出确切数字 |
| C | 通行做法或常识，没有直接文献 |

失恋研究大多是欧美大学生的问卷和日记研究，随机试验很少。所以这本手册里 B 级、C 级多，A 级大多是法条和官方文件。我们照实标，不往上抬。

每条换回的东西分五种：情绪、睡眠和身体、钱、人身安全、社会关系。五种之间不比大小，也不互相折算。
